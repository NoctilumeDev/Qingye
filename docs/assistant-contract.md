# 校园助手能力合同 v2

2026-10-08 经用户确认：模型解释开放语言，本地约束有限能力，用户纠正对自己意图的理解。
本合同替代旧版“模型不得覆盖本地猜测的查询类型”，保留身份、只读、固定查询和展示字段边界。
历史对照与中间请求切分器的失败记录不改写成新版本通过。

## 有限计划

模型只输出单个 JSON，六个字段均须存在，不能有额外字段：

```json
{"action":"QUERY","intent":"EQUIPMENT","entity":"相机","category":null,"timeOption":"CURRENT","reason":null}
```

`action` 为 QUERY、CLARIFY、REJECT。QUERY 只支持公开活动、器材库存、当前账号报名、当前账号借用。
CLARIFY 区分信息不足、多个有效请求、未知对象和不支持的筛选；REJECT 表示请求不允许执行。
不会把两者合并成 OUT_OF_SCOPE。模型没有用户 ID、SQL、接口地址、任意返回字段、写操作或多动作编排权。
含额外字段或多个计划的响应拒绝执行；格式/供应商失败只有少量完整标准入口可以本地兜底。

本地不再切分“现在/之前/算了”等中文，也不以全文关键词猜测的类型否定合法候选。
明显凭据、权限冒充、绕过规则、写操作和他人私有记录仍在全文入口拒绝，夹带合法查询或后续改口不解除拒绝。
无害寒暄和元问题可作为背景；模型应按仍有效的业务动作计数，不按问号数量计数。

## 能力与条件

器材按真实目录名称精确匹配，不把相机、摄像机、摄像头或配件当同一对象。未知或重复对象先澄清；
只有显式 ALL 计划查询全部器材。公开活动可按白名单分类、完整活动标题和有限时间选项查询。
标题须匹配唯一的公开记录；不把未知标题改成无条件查询。现有目录窗口上限仍适用，不声称无限查全。

活动时间选项为 ANY、TODAY、TOMORROW、THIS_WEEK、WEEKEND；器材为 CURRENT、TODAY、TOMORROW、WEEKEND。
服务器注入 Clock 计算上海业务时间的半开区间。CURRENT 器材表示当前实物库存，时段库存另外显示峰值占用后的可用数量。
模型不能提供任意起止时间。本人记录只允许当前会话、ANY，不支持器材/活动名、日期、分类或状态筛选。
已声明的不支持条件必须澄清，不能丢掉后查询更宽范围。

## 语义范围确认

模型遗漏条件仍可能发生，本地不冒充第二个中文解释器。因此开放表达产生的本人查询先返回 CONFIRM_SCOPE，
不读取借用/报名业务记录；正常 HTTP 认证仍核对账号。
页面显示真实范围、固定排除和最多展示10条的限制。继续查询意味着接受该范围，不代表原句已被证明理解正确。
当前账号全部借用记录，或未取消的报名记录，是两种不同的固定范围。

确认绑定当前会话令牌摘要、账号、不可变计划和5分钟服务器期限，一次性使用。
换会话、修改计划、另一次提问、到期或服务重启后重新展示；确认后不再调用模型。
确认状态只在单实例内存持有，不承诺跨节点继续确认；失效会明确提示。
完整标准本人入口且候选相同可以直接查询。公开查询直接执行，并展示实际类型、对象、分类和时间理解。

老师、负责人和管理员不会通过助手获得额外管理查询权：公开信息和当前账号记录的边界对所有角色相同。
工作台仍提供现有履职所需记录、审批和其他操作，由原授权链负责。

## 验证边界

日常 CI 保留有限能力、会话归属、实体、过滤条件、时间、显示字段、范围确认、过期、重放、降级和并发见证。
133题的旧冻结输入另作语义质量对照，不把每句中文编码进长期测试，不以133/133作为安全资格。
新结果保留 QUERY/CONFIRM_SCOPE/CLARIFY/REJECT，并另外展示旧类型 oracle 对照；旧 OUT_OF_SCOPE 无法区分澄清与拒绝。
模型理解正确、权限成立、实际执行正确是不同结论。展示解释和纠正入口不证明模型永远理解正确。
