# 青野语义污染对照实验（2026-10-08）

本轮是测试与问题登记，不包含语义解析产品补丁。查询类型 authority 修复的既有资格不等于自然语言语义正确；本轮确认仍有功能失败。

## 固定条件与证据范围

- 候选源码：`53c31589a4e97eb588beca35938210b5bee9fb76`。两个 provider 在同一候选上运行，中途没有修改业务代码。
- [冻结输入表 v1.1](semantic-probe-plan-v1.1.json)：133 个问题、相同顺序，21 个没有明确类型预期的歧义/不支持问题不计入类型成绩。
- 两次 H2 全表快照逐字一致：学生/另一学生、公开活动/隐藏草稿、本人/他人借用、六种独立器材。相机 5、摄像机 2、手机 4、投影仪 3、相机充电器 1、摄像头 2。
- 固定 Clock：上海 2026-10-08 01:00；同一生产 system prompt、五字段 JSON、temperature 0、300 输出 token、thinking 关闭、5 秒外部 deadline、无自动重试。
- 原生产品链保持全部门禁。另对 17 个被本地拒绝/超长的样例单独调用 planner，只观察模型，不执行查询，不计作产品接受或执行。
- 托管 AssistantService + 实际 provider HTTP + H2；不是微信真机、常驻 HTTP 服务或 MySQL 并发验收。本轮没有重新执行那些链路。
- DeepSeek 使用 `deepseek-flash`，千问使用 `qwen-plus`；thinking 关闭采用各供应商的协议字段。模型别名背后的版本未冻结。每题每模型一次采样，结果不能推广为通用模型排名。

## 两种偏差如何相遇

仅看可评分、可解析的原生产品调用：

| 模型类型 / 产品最终类型 | DeepSeek | Qwen |
| --- | ---: | ---: |
| 都正确 | 44 | 59 |
| 模型错误，产品正确 | 18 | 2 |
| 模型正确，产品错误 | 9 | 12 |
| 都错误 | 2 | 0 |

这里“模型正确”仍只指类型；参数也可能错。单独 planner 诊断不进入此矩阵，避免把绕过产品门禁的观测冒充真实用户执行。

## 停止线与后续入口

本轮停止于冻结表完成、原始结果保留、问题分类和环境清理；未为提升成绩改 system prompt、放宽 validator 或修改本地类型所有权。新发现登记为语义功能问题：历史/否定/撤销的作用域、同域多意图、关键词优先级及误拒。后续应按最小反例分别裁决，先明确“不确定时澄清”的产品合同，再授权窄补丁；不把“模型多数时候理解对”升级成执行权。

原生输入最多 300 字符。301/500/1024 字符在 Bean Validation 入口拒绝；超长文本的额外模型观测不是产品支持证明。日期、类别、歧义指代和完整语义没有统一冻结 oracle，本表不宣称全部覆盖。

测试助手未成为默认测试或永久 benchmark 基础设施。原始计划、临时 helper、两份 JSON 结果和必要首败记录保存在本轮受控本机证据目录；图书馆 provider 调试日志已脱敏。凭据只用于子进程，测试后清除；原用户聊天中的密钥仍需用户在供应商侧注销。
