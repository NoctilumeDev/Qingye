# 独立用户测试与反馈处理

2026-10-01。按用户要求，由独立子智能体操作本机微信小程序，主线程整理产品反馈并与用户商定修正。完整原始报告、64 张截图及动作记录保留在被忽略的 `runtime/user-test/`，不将会话或私人配置提交。

## 用户测试

1. **五账号称呼弹窗：通过。** 统一自定义白卡，身份只读且保持姓名后缀。取消、遮罩关闭和空昵称校验通过；赵六真实保存、离开后读取，再恢复原名。手机软键盘未能在模拟器出现，仍待真机检查。
2. **入口与返回：通过。** 发现筛选和关键词、工作台页签、所选社团及滚动位置保留；社团返回发现或我的实际入口。详情打开使用组件真实事件方法，工具不能穿透卡片内部选择器。
3. **报名与消息：通过。** 赵六真实报名、取消后名额恢复；全部已读、取消清理、只清理选中而保留未选中、全选和退出选择通过。本轮仅清理自己新产生的消息，原有消息保留；原生确认结果临时模拟，结束已恢复。
4. **预约默认时间：发现并修正。** 原默认今天，与未来活动不一致。用户选择首次及切换活动跟随活动起止时间，允许人工调整；表单补充所选活动时间。已开始的活动须把预约开始改为未来时间。
5. **演示数据：发现并清理。** 用户批准备份后清理 9 个测试社团、9 类已停用器材、10 个已取消活动及 11 条成员、18 条报名、19 条结束借用。事务校验 ID、数量、名称和状态，并逐行比对正常业务、用户、通知和任务未变。剩余正常 3 社团、4 器材、5 活动、1 借用。首次清理校验因 Windows 源文件编码失败，整笔回滚；明确 UTF-8 后校验及提交通过，保留原失败日志。备份 SQL 留在忽略目录，不提交。
6. **助手可读性：发现并修正。** ISO 时间改为 `MM-dd HH:mm`，借用状态改为中文，按意图给空态；空问题点击查询给输入提示。日期、全部六种借用状态和空态通过真实业务转换后的 HTTP 测试。
7. **空搜索退出：按用户追加要求修正。** 搜“素123456”无结果时提供清除搜索返回列表，搜索框旁可取消。清除关键词保留原分类，与详情页返回保留搜索上下文的行为兼容。

资料未加载时点击编辑的空对象风险来自源码检查，正常网络未复现；已补重试提示，单独回归。社团待审申请撤回未在现有数据复现，未擅自新增功能。
