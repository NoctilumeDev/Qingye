# 自己查找：分类选择与独立筛选

本次修改从 `7d1668d4bba08ced2f51dfd2aca527009f7faad0` 开始，只改小程序交互、展示和对应客户端测试。

## 用户路径

进入“自己查找”后，选择校园活动、器材库存、我的报名、我的借用中的一至四类，再开始查找。
所选类别出现在顶部，首次打开一类时查询该类的默认范围。每类分别保留名称、筛选条件、结果和分页凭据。
筛选只出现在对应类别内；取消筛选恢复进入筛选前的条件。返回类别选择保留已选内容；页面原生返回回到青野，并保留原问题和查询结果。

移除旧的“保存这一项、添加下一项、一起查”组装流程。手动页面使用独立控制器，问青野保留自然语言、澄清、纠正和反馈流程；两页共用结果格式化与卡片展示。
后端、模型提示词、四道门和能力协议没有修改。

从青野带入的条件先供用户编辑，尚缺的必填条件保持待补充；不以普通目录的默认值覆盖它们。
同一类别的多个已带入查询分别保留。筛选已修改时，旧结果和旧分页操作暂时隐藏，提交后更新。
