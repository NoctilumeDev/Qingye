# 校园助手能力合同 v4.1

本轮只改青野程序及测试，不改此前冻结研究或据此撰写论文。v3 运行记录保留，新程序不沿用旧词表准确率作为验证结论。

v4.1 修正全轮 v4 真实审查暴露的两处本地缺口：复合 `CLARIFY` 顶层允许 `BATCH`（其他条件在子草稿中，仍不能执行），以及追问／手选时间选项按对象能力生成，器材不再收到过去、泛未来或全部时间的选项。v4 原始失败不倒算成修复后通过。

## 一份能力定义

`backend/src/main/resources/assistant-contract.json` 是版本、对象、时间、状态、器材名称分组和查询含义的共同来源。后端 `AssistantContract` 读取它，模型的同一份 `assistant-planner.txt` 附带此定义；`scripts/sync-assistant-contract.py` 生成小程序选项。`--check` 纳入客户端检查，版本不匹配的响应不能恢复执行令牌。

更换兼容 chat-completions 模型时配置 URL、Key、model；不另写厂商业务提示词。厂商 thinking 开关是传输适配，不能扩大业务能力。同一合同不保证任意模型都能正确映射，换模型仍需业务验收。新器材原名、新活动标题不需要写入提示词；名称分组如需变化，应改清单并重新验收，不能以模糊相似名称冒充同一设备。

## 对象与组合

| 能力 | 过滤与事实含义 |
| --- | --- |
| 公开活动 | 启用社团的已发布活动，标题／社团包含词、活动分类、精确地点、活动时段 |
| 我的报名 | 当前会话用户现存的报名，含取消、现已停用社团；日期按活动时段；报名不是出席 |
| 我的借用 | 当前会话用户的借用状态、原名／声明分组、计划借用时段；不是实际归还日期 |
| 器材库存 | 原名／声明分组或明确全部；当前库存、未结束且一年内具体时段的预约可用量；含停用目录，不代表可借 |

今天／明天／后天／指定日采用上海时区半开区间与记录相交。过去按结束时间、当前按进行中、未来按未开始；本周和本周末是剩余时段，下周是下周一至再下一周一。没有完整历史、出席、器材存放地点、采购或未来保证等数据时不能推断。

允许 2—4 项相互独立的查询，各自预览、确认和分页。不是任意 SQL、关系代数或流程编排：不提供跨对象 JOIN、集合差、人数筛选、极值排序、冲突计算、动作日期筛选或依赖链。理解了但不支持时必须说明；不能自动去掉限制只做支持部分。

完整活动卡可覆盖地点、时间等局部问题；这不会自动使错误对象、遗漏目标或被丢弃的硬条件变正确。宽候选与完整对象是两种不同的扩大，不能混用。明确“全部”只放开相应维度，保留其他条件。

## 交互状态

1. 模型生成 `QUERY`、不可执行的 `CLARIFY` 草稿或 `REJECT`。完整协议九个基础字段及可选单层 `queries`，不接受用户ID、SQL、任意返回字段、未知字段、嵌套批次或重复JSON键。
2. 合法完整计划只进入 `CONFIRM_SCOPE`，此时不查询业务记录。显示实际字段、主体和时间含义；用户逐项确认后固定 handler 执行相同计划，不再调用模型。
3. 有必要的缺口或拿不准时，返回问题、已理解草稿和一次性 `clarificationToken`。用户回答 `/assistant/clarify`，服务器带完整原请求和有序补充重新映射，不通过本地中文猜测补槽。
4. 完整预览也可用 `amendmentToken` 主动改口。消费后先作废同请求的全部旧确认及分页令牌，再重新映射。每个请求最多两次补充／修正，仍不明白则 `NOT_UNDERSTOOD`；新请求可重新开始。已执行的读取不因此被撤销。
5. 解析服务超时、无有效响应或异常为 `SYSTEM_ERROR`。可用不同用途的 `retryToken` 显式重试原上下文，不能借重试令牌改写用户答案或绕过澄清次数；不自动重试。手选分区始终可用。

令牌是单实例内存中的随机引用，绑定主体、会话、请求和五分钟总期限；新问题使旧请求失效。跨午夜后的补充／重试要求重新提问，避免“明天”等指代漂移；已经展示的固定日期确认仍遵循其原日期和原到期时间。端点混用、错误主体、错误会话、重复消费均不能取得业务数据。

| 结果 | 含义 |
| --- | --- |
| CLARIFY | 有可补充问题，尚未执行；草稿不是执行授权 |
| NOT_UNDERSTOOD | 有限补充后仍无法理解，停止本轮解析 |
| UNSUPPORTED | 理解了需求但合同或数据不支持，不偷偷删条件 |
| REJECT | 他人私有信息、写操作等请求不允许执行 |
| SYSTEM_ERROR | 系统／模型解析不可用或无效，不归因用户没说清 |
| QUERY + 空列表 | 按已确认条件查无匹配，不能推出历史从未有过 |

## 事实与本地兜底

本地只做结构校验、会话主体绑定、令牌与时段绑定、有限 SQL 和字段投影。删除 v3 的本地自然语言词表和整句快捷兜底，不会因为“名单／谁／某专名”等词直接重写或拦截一个合法业务问题。模型可能仍误判隐私或遗漏条件，因此此结构不等于语义正确性证明。

描述字段作为“记录原文”展示，不再次送给模型作指令。其他用户的记录、私有原因和内部字段不进入展示投影。确认、澄清和分页不产生业务写操作。

分页是同一计划下的当前状态读取，不是跨页快照。前页后如果有取消、改期或新增，结果可能变化；界面和返回说明此边界。网络中断保留已收到行并明确“不完整”，不盲目重放可能已消费的令牌；重新预览范围后再查。被动打开详情再返回保留尚有效的分页入口，离开时仍在处理的请求不能迟到恢复旧凭据。
